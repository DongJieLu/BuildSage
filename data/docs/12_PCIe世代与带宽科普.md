# PCIe 世代与带宽科普

PCIe（PCI Express）是显卡、固态硬盘与 CPU 之间的数据高速路。理解 PCIe 世代与通道数，能回答"老主板插新显卡亏多少"这类高频问题。

## 世代与带宽

每一代 PCIe 的单通道带宽翻倍：

| 世代 | 单通道带宽 | 时代 |
|---|---|---|
| PCIe 3.0 | ~1 GB/s | 2012-2020 主流 |
| PCIe 4.0 | ~2 GB/s | 2020 起主流 |
| PCIe 5.0 | ~4 GB/s | 2023 起旗舰 |

显卡物理形态是 **x16**（16 通道）：PCIe 4.0 x16 的单向带宽约 32 GB/s，PCIe 5.0 x16 约 64 GB/s。

## 向下兼容规则

PCIe **向下兼容**：PCIe 5.0 显卡可以插在 3.0/4.0 主板上，按低的世代运行；新主板插老显卡同理。也就是说"插不上"不存在，"跑不满"才是问题。

## 对显卡性能的真实影响

现代显卡在 x16 槽位上，3.0 与 4.0 的游戏帧数差距通常在 1~3% 以内——因为显存里的素材多数驻留本地。真正受影响的是**显存爆掉需要回传数据**的场景（显存不足、超大纹理流送），此时老世代带宽会放大卡顿。

x8 与 x16 的差异同理：RTX 4060 用 PCIe 4.0 x8（等效 3.0 x16），在 4.0/5.0 主板上几乎无性能损失，在老 3.0 主板上则可能损失 3~5%。

## 对固态硬盘的影响

PCIe 4.0 NVMe 顺序读写约 7000 MB/s，5.0 约 12000 MB/s。但游戏加载时间 4.0 与 3.0 的差距已经缩小到秒级以下——系统响应的瓶颈更多在随机读写与主控，不必为 5.0 SSD 单独追高主板。

## 通道数从哪来

CPU 直出通道有限（AM5 / LGA1700 约 20~28 条）：显卡 x16 + 一条 M.2 x4 是典型分配，再多的 M.2 要靠主板芯片组（Southbridge）分出，延迟略高。

## 选购建议

1. 显卡买家不必为 PCIe 5.0 槽位加钱，4.0 足够。
2. 老主板（3.0）升级新显卡前，先确认自己的分辨率与显存压力。
3. 小机箱 ITX 主板的 x16 槽若只有 x8 物理长度，选卡前查清楚。
4. 512GB 的 3.0 SSD 与 7000MB/s 的 4.0 SSD 在"打开软件"场景感知差异很小。
