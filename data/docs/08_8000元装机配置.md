# 8000 元 2K 游戏装机配置推荐

8000 元是 2K 分辨率游戏机的舒适区间。这个预算的关键决策是"显卡档位"：RTX 4070 SUPER 或 RX 7800 XT 级别，2K 高画质 + 165Hz 高刷屏刚好喂饱。

## 配置清单

| 配件 | 型号 | 预算参考 |
|---|---|---|
| CPU | AMD Ryzen 7 7700 或 i5-14600KF | ~1200 元 |
| 主板 | B650M（AM5）/ B760M（Intel） | ~900 元 |
| 内存 | DDR5 6000 32GB (2x16) | ~650 元 |
| 显卡 | RTX 4070 SUPER 12GB | ~4200 元 |
| 电源 | 750W 80PLUS 金牌（ATX 3.0） | ~500 元 |
| 固态 | 1TB NVMe PCIe 4.0 旗舰 | ~550 元 |
| 散热 | 240 水冷或双塔风冷 | ~300 元 |
| 机箱 | 风道优先 M-ATX/ATX | ~300 元 |

合计约 8600 元，选 A 卡 RX 7800 XT（约 3800 元）可控制在 8200 元内。

## 思路解读

- **CPU 不必追旗舰**：2K 分辨率下显卡是主要瓶颈，7700（65W 低功耗、免散热焦虑）或 14600KF 足以喂饱 4070 SUPER。
- **显卡吃掉一半预算**：2K 高画质 + 光追开 DLSS/FSR，4070 SUPER 12GB 显存很从容。
- **电源留一档升级空间**：750W 金牌 ATX 3.0，未来换 4080 级显卡也基本够用。

## 功耗与兼容性核对

- 功耗预算：7700（120W）+ 4070 SUPER（220W）+ 80W ≈ 420W，750W 从容。
- 内存：AM5 只收 DDR5；LGA1700 的 B760 板注意选 DDR5 版本。
- PCIe：4070 SUPER 是 PCIe 4.0，B650/B760 主板直出 PCIe 4.0 x16，满速。
- 机箱限长：4070 SUPER 非公约 270~310mm，主流中塔都能装。

## 显示器搭配建议

这套配置的"正确打开方式"是 2K 165~180Hz IPS 高刷屏。1080P 屏会让显卡过剩，4K 屏则会显卡不足——整机预算与显示器档位要匹配。

## 可替换项

- 电竞优先：CPU 换 7800X3D，显卡降一档到 4060 Ti，电竞帧数更高。
- 生产力兼顾：CPU 换 14600K（14 核），内存加到 48GB。
- 预算超支救急：机箱散热先随便，绝不在显卡和电源上省钱。
