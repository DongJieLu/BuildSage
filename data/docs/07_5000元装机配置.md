# 5000 元游戏装机配置推荐

5000 元是 1080P 游戏主机的黄金预算段：核心思路是把钱花在显卡上，CPU 选甜点，其余件够用就好。以下是一套参考配置（价格随行情浮动）。

## 配置清单

| 配件 | 型号 | 预算参考 |
|---|---|---|
| CPU | AMD Ryzen 5 7500F | ~750 元 |
| 主板 | MSI PRO B650M-A WIFI | ~800 元 |
| 内存 | DDR5 6000 32GB (2x16) | ~650 元 |
| 显卡 | RTX 4060 8GB | ~2300 元 |
| 电源 | 650W 80PLUS 金牌 | ~350 元 |
| 固态 | 1TB NVMe PCIe 4.0 | ~400 元 |
| 散热 | 四热管风冷 | ~100 元 |
| 机箱 | ATX/M-ATX 风道款 | ~200 元 |

合计约 5500 元，若用 AM4 平台（5600 + B550 + DDR4）还能再压下 600~800 元。

## 思路解读

- **CPU 选 7500F**：6 核 12 线程，游戏性能与 7600X 几乎一致，不带核显更便宜。它落在 AM5 平台，后续能升级 9800X3D 这类游戏神 U。
- **显卡给足预算**：这个价位把最多钱给显卡是对的——1080P 高画质 3A 与 2K 网游都靠它。
- **内存 32GB 一步到位**：DDR5 6000 是 AM5 甜点频率，2x16GB 双通道。

## 功耗与兼容性核对

- 功耗预算：7500F 65W + RTX 4060 115W + 余量 80W ≈ 260W，650W 电源绰绰有余。
- 插槽：7500F 是 AM5，配 B650 主板，匹配。
- 内存：AM5 平台只能 DDR5，选 6000MT/s 套条并开 EXPO。
- 机箱：M-ATX 主板，选 ATX 或 M-ATX 机箱均可。

## 升级路线

未来三年内：显卡升级到 4070 级别时电源 650W 依然够用（4070 约 200W）；CPU 可升级 AM5 全系。这套配置的"地基"留足了升级空间。

## 可替换项

- 想再省：换 AM4 平台 5600 + B550 + DDR4 3600，性能损失约 5~10%。
- 想加钱：显卡升 RTX 4060 Ti 或 RX 7700 XT，2K 显示器体验明显更好。
- 核显亮机党：直接用 8700G/8600G，暂不买显卡也行，但游戏性受限。
