# 主板选购指南：芯片组、插槽与供电

主板本身不影响帧数，但它决定了 CPU 能不能装、内存用几代、显卡跑不受 PCIe 满速。选主板的本质是"为 CPU 和未来升级选平台"。

## 第一步：插槽必须与 CPU 一致

这是所有兼容性检查的第一条：

- Intel 12~14 代 → **LGA1700**；Core Ultra → **LGA1851**；10~11 代 → LGA1200；更老 → LGA1151。
- AMD 锐龙 7000/9000 → **AM5**；锐龙 3000/5000 → **AM4**。

不同插槽物理针脚不同，装不进去就是装不进去。买板前先确认 CPU 的插槽，或者反过来先定主板再挑 CPU。

## 第二步：内存代数

同一颗 LGA1700 CPU 既有 DDR4 版主板也有 DDR5 版主板，型号里带 "D4" 字样的用 DDR4。AM5 与 LGA1851 平台只有 DDR5。买内存前务必核对主板的内存代数，这是第二容易翻车的兼容点。

## 芯片组等级怎么看

Intel 侧（LGA1700）从低到高：H610 < B660 < B760 < Z690/Z790。要点：

- **B 系**：主流之选，支持内存超频（B660/B760），性价比最高。
- **Z 系**：支持 CPU 倍频超频（配 K 系列 CPU），接口与供电规格更高。
- **H 系**：入门办公，通常不支持内存超频。

AMD 侧：B450/B550（AM4）、B650/B850（AM5）为主流，X570/X670E 为高端，"E" 后缀表示主板直出 PCIe 5.0 通道。

## 供电与散热

同一芯片组不同价位的主板差距主要在供电相数与散热马甲。带 K 的 i7/i9 建议选 12 相以上供电的型号；i5 / 锐龙 7 以下 B 系中板完全够用。

## 接口与扩展

- 显卡插槽：PCIe 4.0 是当前主流，PCIe 5.0 面向未来（对现有显卡性能影响很小）。
- M.2 数量：至少 2 个，注意 PCIe 5.0 SSD 会与显卡抢通道的主板要查手册。
- 后置 USB 与网络：2.5G 网卡已是主流标配。

## 板型与机箱

ATX 标准大板、M-ATX 紧凑主流、ITX 小钢炮。机箱要先确认支持的主板板型上限。

## 常见避坑

1. "CPU 支持"与"开箱即用"是两回事，AM4 装新 U 可能要先刷 BIOS。
2. DDR4 板与 DDR5 板价格可能倒挂，看清型号再下单。
3. 追求 WiFi 的话，B 系高配版通常自带 AX/WiFi6E/7，低配没有。
4. 供电不足的廉价 Z 系主板喂不饱 i9，不如选供电扎实的 B760。
