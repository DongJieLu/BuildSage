# CPU 选购指南：游戏与生产力怎么分

CPU 是平台的"地基"，它决定了主板插槽、内存代数，甚至电源规格。选 CPU 先想清楚两件事：主要用途是什么、预算内它要和显卡怎么分配。

## 游戏与生产力的分水岭

- **游戏为主**：优先看单核性能与三级缓存。带 3D V-Cache 的 AMD 锐龙 7 9800X3D / 7800X3D 是公认的游戏甜点，缓存翻倍带来在电竞与开放世界游戏里的显著帧数优势。
- **生产力为主**（渲染、编译、虚拟机）：优先看核心与线程数量，锐龙 9 7950X / 9950X 或 Intel i9 系列的多核吞吐更划算。
- **混合用途**：i5-14600K / i7-14700K 或锐龙 7 9700X 这类中间档，兼顾得比较好。

## Intel 平台速览

- **12~14 代（LGA1700）**：i5-13600K / 14600K 是 14 核心（6 性能核 + 8 能效核）的甜点；i9-14900K 面向旗舰玩家，注意最大睿频功耗 253W，散热与电源要跟上。
- **Core Ultra（LGA1851）**：核显与 NPU 增强，主打能效与 AI 特性，仅支持 DDR5。

## AMD 平台速览

- **AM4（锐龙 3000/5000 系）**：DDR4 平台的性价比之王，5600/5700X/5800X3D 至今能战，适合省钱升级老平台。
- **AM5（锐龙 7000/9000 系）**：DDR5 + PCIe 5.0，后续还能升级下一代 CPU，装机预算允许时优先考虑。

## 与显卡的预算配比

游戏整机里"处理器 + 显卡"占预算大头，常见配比思路：

- 1080P 电竞：CPU 略强，显卡中档（如 RTX 4060 级），保证高帧率低延迟。
- 2K 均衡：CPU 与显卡五五开（如 7700X + RTX 4070 SUPER）。
- 4K 高画质：瓶颈在显卡，CPU 中档即可（如 7500F + RTX 4080 级）。

## 散热与功耗提醒

- i9 级别建议 360 水冷起步，i5/锐龙 7 级别风冷旗舰或 240/280 水冷即可。
- 盒装自带散热器仅够点亮，不建议长期游戏使用。
- 关注 CPU 的最大睿频功耗而非基础 TDP，这直接决定散热器与电源的选择。

## 常见避坑

1. 别为游戏买 16 核——多数游戏吃不到，省下的钱加到显卡上更划算。
2. K 系列（Intel）需要 Z 系主板才能超频，锁频 CPU 配 B 系主板更省钱。
3. AM4 平台装 5800X3D 前确认主板 BIOS 已更新支持。
4. X3D 型号不支持超频，配套主板不必追高规格。
