# 装机兼容性避坑清单

新手装机翻车，八成翻在兼容性上。这篇把最常见的兼容性错误汇总成清单，下单前逐条核对，可以避开 90% 的事故。用装机参谋的"兼容校验"功能也能自动核对以下各项。

## 一、插槽匹配（最高频事故）

CPU 与主板的插槽必须完全一致：

- Intel 12~14 代 = LGA1700；Core Ultra = LGA1851；10/11 代 = LGA1200。
- AMD 锐龙 7000/9000 = AM5；锐龙 3000/5000 = AM4。

**典型事故**：买了 7800X3D 配 B550 主板（AM4 板装不上 AM5 的 CPU）；或者反过来，AM4 老 CPU 配 B650 主板。

## 二、内存代数（第二高频事故）

DDR4 与 DDR5 的缺口位置不同，物理上就插不进去：

- AM5、LGA1851 平台：只有 DDR5。
- LGA1700 平台：主板分 DDR4 / DDR5 两个版本，看型号后缀（D4 / DDR5）。
- AM4 平台：只有 DDR4。

**典型事故**：给 B650 主板买了 DDR4 内存。下单前把"CPU、主板、内存"三件的内存代数排成一排看一眼。

## 三、电源功率与接口

1. 功率核算：CPU 最大睿频功耗 + 显卡功耗 + 80W 余量。i9-14900K + RTX 4090 需要 850W 起步。
2. 旗舰显卡（4090/4080）需要原生 12VHPWR 或足够数量的 PCIe 8pin 接口。
3. 显卡厂商标注的"推荐电源功率"已含余量，两套标准取高者。

## 四、机箱限长与限高

1. 旗舰非公显卡长度 320~360mm，对照机箱"显卡限长"参数。
2. 塔式风冷限高 155~168mm，对照机箱"散热器限高"。
3. 360 冷排需要机箱顶部/前部支持 360mm 排位。

## 五、平台组合的连带关系

1. AM4 老 CPU 装新主板（或反过来）可能需要先刷 BIOS，确认主板有 BIOS FlashBack 按钮。
2. K 系列超频需要 Z 系主板；B 系只能超内存。
3. 高频内存（DDR5 6800+）在 AM5 上四条插满可能降频，两根更稳。

## 六、快速自检流程

下单前花三分钟过一遍：

1. CPU 插槽 = 主板插槽？
2. 内存代数 ∈ 主板支持 ∩ CPU 支持？
3. CPU 最大功耗 + 显卡功耗 + 80 ≤ 电源额定？
4. 显卡长度 ≤ 机箱限长？散热器高度 ≤ 机箱限高？
5. 显卡 PCIe 世代 vs 主板世代（差一代可接受，会提示带宽降级）？

以上第 1~3 条是"硬冲突"（装不上或点不亮），第 4 条是物理装不上，第 5 条是性能提示。全部通过再付款，能省下绝大多数售后折腾。
