# 显卡选购指南：按分辨率与场景挑卡

显卡通常是整机预算里最贵的一件，也直接决定游戏体验。挑显卡的正确顺序是：先确定显示器分辨率和目标帧率，再看预算，最后核对电源与机箱。

## 按分辨率选档位

- **1080P 电竞 / 高刷**：RTX 4060、RX 7600 一档即可拉满多数网游；追求光追与高画质可选 RTX 4060 Ti。
- **2K 主流**：RTX 4070 / 4070 SUPER、RX 7700 XT / 7800 XT 是甜点区间，2K 高画质 + 高刷新率兼顾。
- **2K 高刷 / 4K 入门**：RTX 4070 Ti SUPER、RX 7900 XT。
- **4K 高画质**：RTX 4080 SUPER / 4090、RX 7900 XTX。

## 显存大小为什么重要

3A 大作在高画质下显存占用快速上升，2K 建议至少 12GB，4K 建议 16GB 起。同型号显存更大的版本（如 4060 Ti 16GB）在高画质场景更从容；显存不足时帧数会"断崖式"下跌而不是平滑下降。

## A 卡与 N 卡怎么分

- **NVIDIA**：光追性能与 DLSS 生态领先，创作软件适配广，旗舰段位强势。
- **AMD**：同价位传统光栅性能通常更足，FSR 不挑显卡，价格策略激进。
两家的超采样技术（DLSS / FSR）都能大幅提升帧数，能开尽量开。

## 电源与功耗匹配

看两处：显卡 TDP 与厂商标注的"推荐电源功率"。RTX 4070 约 200W（推荐 650W），RTX 4090 约 450W（推荐 1000W 更稳）。功耗预算核算别只看显卡，CPU 最大功耗也要加进去（详见电源功率计算篇）。

旗舰卡瞬时功耗尖峰很高，ATX 3.0 电源对瞬时超载的容忍度更高，搭配更省心。

## 机箱兼容性

- 旗舰非公卡长度普遍 320~360mm，下单前量机箱限长。
- 三槽厚的非公卡注意与竖装显卡位、前方风扇的冲突。
- 小机箱优先考虑双风扇短卡或 ITX 专用卡。

## 常见避坑

1. 别用"跑分"当唯一标准，实际游戏帧数与显存容量更真实。
2. 矿潮翻新卡风险高，二手尽量选个人自用并有购买凭证的。
3. 公版 / 非公差异主要在散热与噪音，核心性能差距通常在 1~3%。
4. 电竞游戏（CS2、无畏契约）帧数瓶颈常在 CPU，显卡不必拉满。
