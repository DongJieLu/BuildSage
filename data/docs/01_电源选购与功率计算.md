# 装机电源选购与功率计算指南

电源是整台主机的"心脏"，也是最容易被低估的配件。电源选小了会触发过载保护黑屏重启，长期高负载还会加速老化；选大了则浪费预算。本篇讲清楚功率怎么算、瓦数怎么留余量、认证怎么挑。

## 功率怎么算

估算整机的持续功耗，只需要抓住两个大件：

- **CPU**：看 TDP 与最大睿频功耗，取较大值。例如 i9-14900K 基础功耗 125W，最大睿频功耗 253W，计算时应按 253W 计。
- **显卡**：看 TDP/TBP。RTX 4090 约 450W，RTX 4070 约 200W。

其余部件（主板、内存、一块 NVMe 固态、三五个风扇）合计通常不超过 50~80W。一个简单的估算公式：

> 整机需求 ≈ CPU 最大功耗 + 显卡功耗 + 80W 余量

以 i9-14900K + RTX 4090 为例：253 + 450 + 80 = 783W，因此 850W 是起步线，追求安静与效率建议 1000W。

## 瓦数档位怎么选

- **核亮机 / 办公机（无独立显卡）**：CPU 加 80W 余量，通常 450~550W 足够。
- **主流游戏机（RTX 4060 / 4070 级别）**：650~750W。
- **高端游戏机（RTX 4080 / 4090 级别）**：850~1000W。
- **旗舰平台 + 超频**：1000~1200W。

留余量的好处不只是安全：电源在 50%~70% 负载区间转换效率最高、风扇转速最低，长期处于额定值边缘反而又吵又费电。

## 认证与+12V 输出

80PLUS 认证反映转换效率，从低到高为白牌、铜、银、金、铂金、钛金。主流装机建议至少 80PLUS 金牌。比认证更重要的是 **+12V 单路输出能力**——显卡完全吃 12V，选购时确认 12V 输出接近额定功率即可。

## ATX 3.0 与原生 12VHPWR

RTX 40 系显卡建议优先选择 **ATX 3.0 标准、原生 12VHPWR（16pin）接口**的电源，避免使用转接头。若电源较老，务必用厂商附带的转接线，不要用第三方廉价转接。

## 模组化与尺寸

- **全模组**：只接需要的线，背线整洁，优先推荐。
- **直出（非模组）**：便宜，适合预算紧张或线材要求低的配置。
- 小机箱注意 SFX 规格，与标准 ATX 电源不通用。

## 常见避坑

1. 不要买无认证的"标牌电源"，虚标瓦数是重灾区。
2. 二手电源风险高，电容老化不可见。
3. 电源质保年限是厂商信心的体现，主流大厂金牌通常 7~10 年保。
4. 双 8pin 供电的旗舰显卡，确认电源具备对应接口数量。
