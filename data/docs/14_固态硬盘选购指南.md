# 固态硬盘选购基础指南

固态硬盘（SSD）决定系统与游戏的加载体验。SSD 的性能参数看着眼花，实际选购只抓三个点：接口协议、容量、主控与颗粒。

## 接口与协议

- **NVMe M.2 PCIe 3.0**：顺序读写约 3500 MB/s，系统盘的入门门槛，价格已非常友好。
- **NVMe M.2 PCIe 4.0**：约 7000~7400 MB/s，当前装机的主流选择，价差小，优先。
- **NVMe M.2 PCIe 5.0**：12000+ MB/s，发热大（需要散热片），对游戏体验提升有限，生产力用户再考虑。
- **SATA 2.5 寸**：约 550 MB/s，老平台扩容用，新装机基本不再推荐。

注意主板 M.2 插槽支持的协议与世代——CPU 直出的 M.2 通常为 PCIe 4.0 x4，芯片组出的可能为 3.0 x4。

## 容量怎么选

- **500GB**：只装系统与常用软件，游戏玩家很快就不够。
- **1TB**：游戏装机起步容量，3A 大作单个 100GB+ 的时代，1TB 很快也会紧张。
- **2TB**：当前性价比甜点，推荐游戏玩家直接上。
- **4TB**：素材库、游戏库重度用户。

## 缓外速度与颗粒

顺序速度是"缓存内"成绩，写入超过缓存容量后（拷贝大文件）速度回落到"缓外"水平。缓外性能取决于颗粒与主控方案：TLC + DRAM 缓存的主流方案即可放心；无 DRAM 的入门方案（HMB）日常用也没问题，但持续写入弱。

## 游戏加载真的快吗

从 SATA 升级到 NVMe 3.0/4.0，游戏加载时间的改善远不如从机械盘升级时明显——多数 3A 游戏加载瓶颈在引擎与 CPU 解压。选择顺序：容量够 > 4.0 协议 > 顺序分数。

## 稳定性与售后

1. 优先选原厂颗粒品牌（三星、铠侠、致钛、西数、美光等）。
2. 质保写 TBW（总写入字节数）与年限，主流为 5 年 / 600TBW 起。
3. 直播盘、监控盘等"矿盘"渠道风险高，二手 SSD 谨慎。
4. 主板 M.2 位自带散热马甲的，别忘贴导热垫再安装。

## 推荐组合

- 预算机：500GB PCIe 3.0 系统盘（或 1TB 4.0 一盘走）。
- 标准游戏机：1TB PCIe 4.0 系统盘。
- 进阶：1TB 系统盘 + 2TB 游戏仓库盘。
