# DDR4 与 DDR5 内存怎么选

内存代数是装机最容易翻车的兼容点之一：DDR4 与 DDR5 物理缺口位置不同，**插错代数的内存根本装不进主板**。内存、CPU、主板三者的内存代数必须一致。

## 平台决定代数

- **Intel 12~14 代（LGA1700）**：主流 B660/B760/Z690/Z790 主板分为 DDR4 版与 DDR5 版，同一颗 CPU 两种内存都能用，选板时看清楚型号后缀。
- **Intel Core Ultra（LGA1851）**：仅支持 DDR5。
- **AMD AM4（锐龙 3000/5000 系）**：仅支持 DDR4。
- **AMD AM5（锐龙 7000/9000 系）**：仅支持 DDR5。

简单记法：AM5 与 LGA1851 只有 DDR5；LGA1700 看主板版本；AM4 只有 DDR4。

## 性能差距大吗

DDR5 起步频率 4800~5600MT/s，主流甜点为 6000MT/s；DDR4 主流 3200~3600MT/s。对游戏帧数的影响：

- **AM5 平台**：DDR5 6000 是"甜点频率"，与 Infinity Clock 1:1 同步，性能价格比最高。
- **LGA1700 平台**：DDR4 3600 与 DDR5 6000 在多数游戏里差距在个位数百分比，DDR4 版主板搭配 12~14 代依然流畅。

## 容量怎么选

- **16GB（2x8GB）**：办公、网游够用，但 3A 大作已显吃紧。
- **32GB（2x16GB）**：当前游戏装机的推荐容量，双通道组合也最合理。
- **48GB / 64GB**：视频剪辑、虚拟机、本地大模型推理需求再考虑。

## 频率与时序

同代数下频率越高、时序（CL）越低越好，但边际收益递减。优先保证双通道与容量，再追求频率。AMD AM5 平台建议直接选标注 **EXPO** 的套条；Intel 平台选 **XMP 3.0** 套条，装好后进 BIOS 开启一键超频档案。

## 选购清单式建议

1. 数量选两根组双通道，不要一根大容量。
2. 主板只有两个内存槽时，一步到位买 2x16GB。
3. 灯条与普条性能无差，按预算与审美选择。
4. 高频率套条在老主板上可能点不亮，确认主板 QVL 兼容列表。
